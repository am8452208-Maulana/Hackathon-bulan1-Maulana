# 🏍️ MAUL MOTOR
### Motor Sehat. Perjalanan Tenang.

**Nama:** Ahmad Maulana  
**Project:** Website Maul Motor  
**Teknologi:** HTML, CSS, JavaScript

---

## 1. Tentang Maul Motor

Maul Motor adalah sebuah website yang dibuat untuk membantu pengguna mengingat jadwal perawatan motor, seperti servis rutin dan ganti oli.

Website ini ditujukan kepada orang-orang yang menggunakan motor setiap hari, seperti mahasiswa dan pekerja, yang terkadang lupa merawat motornya.

Tujuan saya membuat Maul Motor adalah agar pengguna lebih mudah mengingat jadwal perawatan motor dan menjaga motornya tetap dalam kondisi baik.

---

## 2. Masalah yang Ingin Diselesaikan

Banyak pengendara motor yang sering lupa melakukan servis atau mengganti oli.

Beberapa masalah yang sering terjadi:

- Lupa jadwal servis motor.
- Terlambat mengganti oli.
- Tidak memiliki catatan perawatan motor.
- Kurang memperhatikan kondisi kendaraan.

Jika motor tidak dirawat dengan baik, maka motor bisa mengalami masalah dan mengganggu aktivitas sehari-hari.

---

## 3. Solusi yang Saya Buat

* Maul Motor hadir sebagai website yang membantu pengguna mengingat jadwal perawatan motor.
* Melalui website ini, pengguna dapat melihat informasi kendaraan dan mencoba simulasi pengingat perawatan.
* Harapannya, pengguna bisa lebih teratur dalam merawat motor dan tidak mudah lupa jadwal servis.

---

## 4. Penjelasan Bagian Website

### Navbar

* Navbar adalah menu yang digunakan untuk berpindah ke bagian lain dalam website.
* Menu yang tersedia yaitu Home, Problem, Solution, Demo, Impact, Roadmap, dan System.

### Hero Section

* Hero merupakan bagian pertama yang dilihat ketika website dibuka.
* Bagian ini berisi nama Maul Motor, slogan, penjelasan singkat, dan tombol untuk melihat fitur website.

### Problem

* Bagian ini menjelaskan masalah yang sering dialami pengendara, seperti lupa servis dan lupa mengganti oli.

### Solution

* Bagian ini menjelaskan solusi yang ditawarkan Maul Motor untuk membantu pengguna mengingat jadwal perawatan.

### Demo

* Bagian Demo menampilkan contoh cara kerja website dan simulasi pengingat perawatan motor.

### Impact & Value

* Bagian ini menjelaskan manfaat Maul Motor, yaitu membantu pengguna merawat motor lebih teratur, mengingat jadwal servis, dan menjaga kendaraan.

### Roadmap

* Roadmap adalah rencana pengembangan website ke depannya.
* Rencana pengembangan Maul Motor:

1. Membuat prototype website.
2. Menambahkan akun pengguna dan penyimpanan data motor.
3. Membuat pengingat servis otomatis.
4. Menambahkan fitur riwayat servis dan rekomendasi bengkel.

---

## 5. Teknologi yang Digunakan

### HTML

HTML digunakan untuk membuat struktur website, seperti judul, teks, tombol, gambar, menu, dan formulir.

### CSS

CSS digunakan untuk mempercantik tampilan website, seperti mengatur warna, ukuran tulisan, jarak, dan tata letak.

### JavaScript

JavaScript digunakan untuk membuat website lebih interaktif, seperti membaca data yang dimasukkan pengguna dan menampilkan pesan.

---

## 6. ERD

ERD adalah gambar yang menunjukkan hubungan antara data-data yang ada di dalam sistem.

Pada Maul Motor terdapat 3 data utama:

- **Users:** Data pengguna.
- **Motor:** Data motor milik pengguna.
- **Servis:** Data perawatan motor.

Hubungannya adalah satu pengguna dapat memiliki beberapa motor, dan satu motor dapat memiliki beberapa catatan servis.

Contoh:

Seorang pengguna memiliki motor Honda Beat. Motor tersebut memiliki catatan ganti oli, servis rem, dan servis rutin.

---

## 7. Flowchart

Flowchart adalah gambar yang menjelaskan alur kerja sebuah program.

Alur Maul Motor:

1. Pengguna membuka website.
2. Pengguna memasukkan data motor.
3. Sistem memeriksa apakah data sudah lengkap.
4. Jika belum lengkap, pengguna diminta mengisi kembali.
5. Jika sudah lengkap, sistem memproses data.
6. Sistem menampilkan informasi jadwal perawatan.
7. Proses selesai.

Flowchart membantu saya memahami urutan kerja website sebelum membuat program.

---

## 8. Pseudocode

Pseudocode adalah cara menulis langkah-langkah program menggunakan bahasa sederhana sebelum membuat kode asli.

Contoh pseudocode Maul Motor:

```text
MULAI

Masukkan nama pengguna
Masukkan nama motor
Masukkan jadwal servis

Jika data belum lengkap
    Tampilkan pesan untuk melengkapi data
Jika data sudah lengkap
    Tampilkan jadwal perawatan

SELESAI
```

Pseudocode membantu saya menyusun alur program agar lebih mudah ketika mulai coding.

---

## 9. Cara Kerja JavaScript

JavaScript digunakan untuk menjalankan interaksi pada website.

Pada Maul Motor, JavaScript bekerja dengan cara:

1. Pengguna mengisi nama.
2. Pengguna mengisi nama motor.
3. Sistem membaca data yang dimasukkan.
4. Sistem memeriksa apakah data sudah lengkap.
5. Jika data lengkap, sistem menampilkan pesan berhasil.
6. Jika data belum lengkap, sistem menampilkan pesan agar pengguna melengkapi data.

Dengan JavaScript, website tidak hanya menampilkan informasi, tetapi juga bisa merespons tindakan pengguna.

---

## 10. Tampilan Website (UI & UX)

### UI

UI adalah tampilan website yang dilihat oleh pengguna.

Saya menggunakan warna gelap dan hijau lime agar website terlihat modern, sporty, dan sesuai dengan tema otomotif.

### UX

UX adalah pengalaman pengguna saat menggunakan website.

Saya membuat menu dan informasi sesederhana mungkin agar pengguna mudah memahami isi website dan tidak kebingungan saat menggunakannya.

Website Maul Motor yang saya buat masih berupa prototype atau contoh awal.

Saat ini website belum memiliki:

## 12. Pengembangan ke Depan

Ke depannya, saya ingin mengembangkan Maul Motor dengan menambahkan:

- Login dan registrasi.

Dengan fitur tersebut, Maul Motor diharapkan dapat menjadi website yang lebih bermanfaat bagi pengendara.

---

## 13. Kesimpulan

Maul Motor dibuat untuk membantu pengendara agar tidak lupa merawat motor mereka.

Melalui website ini, saya belajar bahwa membuat website bukan hanya tentang coding dan desain, tetapi juga tentang mencari masalah dan membuat solusi yang bermanfaat bagi orang lain.
